# Contributing

## Before Making Changes

1. Read AGENTS.md
2. Read PROJECT.md
3. Check TASKS.md
4. Check DECISIONS.md
5. Understand the existing architecture

## Development Rules

- Keep changes focused.
- Avoid unnecessary dependencies.
- Write tests for important functionality.
- Preserve provenance.
- Document major architectural changes.

## Research Contributions

Every research contribution should include:
- Source
- Finding
- Relevance
- Confidence
- Implication

## Pull Request Checklist

- [ ] Requirements satisfied
- [ ] Tests pass
- [ ] Documentation updated
- [ ] No unsupported technical claims
- [ ] No provenance lost
- [ ] No unnecessary complexity
