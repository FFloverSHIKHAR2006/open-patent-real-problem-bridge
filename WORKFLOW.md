# System Workflow

## Standard Research Pipeline

1. Receive Problem
2. Normalize
3. Identify Mechanism
4. Generate Search Strategies
5. Retrieve
6. Rank
7. Extract
8. Translate
9. Fuse
10. Apply Constraints
11. Validate
12. Score
13. Present
14. Iterate

## Search Strategies

Use multiple strategies:
- Direct problem search
- Mechanism search
- Material search
- Functional search
- Cross-domain search

## Result Structure

- Problem interpretation
- Recommended mechanism
- Source
- Prototype approach
- Materials
- Steps
- Feasibility
- Risks
- Confidence
- Impact

## Iteration Rules

If evidence is insufficient → return to retrieval.

If mechanism is unclear → return to problem analysis.

If solution is weak → generate alternative mechanisms.

If conflicting evidence exists → surface the conflict.
