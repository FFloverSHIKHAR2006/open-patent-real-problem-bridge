# Innovation Validation

## Validation Objective

Determine whether an idea is:
- Technically plausible
- Useful
- Feasible
- Differentiated
- Supported by evidence

## Validation Process

### 1. Technical Validation
Does the underlying mechanism work?

### 2. Prior-Art Validation
Has the same solution already been implemented?

### 3. User Validation
Does the target user actually need it?

### 4. Constraint Validation
Does it work under real-world constraints?

### 5. Competitive Validation
Is there a meaningful advantage?

### 6. Prototype Validation
Can a minimum version be built?
